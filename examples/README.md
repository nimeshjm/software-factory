# Examples

Worked examples of a target repo onboarded to the factory. They are reference material only; nothing here is loaded by the factory at run time.

- `fantasy-football/`: the original target (a Cloudflare Worker with npm tooling). It shows a fully filled `factory.yml` (every profile section), the `.agents/*.md` context files, issue and PR templates, and an `ONBOARDING.md` with the repo-settings commands.

For a new target start from `templates/target/` instead and fill in its own values.
